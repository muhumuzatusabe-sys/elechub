# Template Engine

Templates are structured documents, not flattened images.

Elements:
TEXT, IMAGE, LOGO, SHAPE, LINE, QR, ICON, BACKGROUND.

Element properties:
id, type, x, y, width, height, rotation, zIndex, opacity, visibility, constraints, style, variableBinding.

Text properties:
fontFamily, fontSize, fontWeight, lineHeight, letterSpacing, alignment, maxLines, overflowStrategy.

Overflow strategies: shrink, wrap, truncate or fail validation.

Batch rendering must flag invalid designs instead of silently producing bad creatives.

# CampusForge — Antigravity Production Package

CampusForge is a production-grade campus campaign creative and communications platform.

Start with `ANTIGRAVITY_MASTER_PROMPT.md`. The `docs/` folder contains implementation specifications for architecture, database, template rendering, batch generation, video, messaging, UI/UX, security and acceptance tests.

Core principle: AI assists with structured copy and creative decisions; deterministic rendering produces final text-heavy graphics so names, spelling, typography and layout remain exact.
